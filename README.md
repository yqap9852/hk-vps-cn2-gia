3. **适合把访问延迟放在优先级较高的位置**

## 购买前建议做一次真实线路测试

任何香港低延迟VPS都不应该只看宣传页面。购买后可以从自己的实际网络进行测试，至少覆盖：

1. 家庭宽带或办公网络；
2. 中国电信、联通、移动中你实际使用的运营商；
3. 白天和晚间高峰；
4. 网站访问、SSH 登录、文件下载和 API 请求；
5. 连续延迟、抖动和丢包，而不是只测一次 ping。

如果业务面向多个城市，最好准备几个不同地区的探针。华南地区的结果不能代表东北、西北或西南地区。第三方测试也只能说明测试者所在时间和网络条件下的表现，不能替代你的实际验证。

对于网站项目，建议同时观察首字节时间、静态资源加载、数据库响应和图片下载速度。服务器 ping 很低，不代表网页一定快。网页速度还会受到程序、数据库、CDN、图片大小和前端脚本影响。
